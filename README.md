# Tangkap Mangga

Tangkap Mangga is a tiny browser game built from a single prompt for the make.fun bounty. Catch falling mangoes, avoid explosive bombs, and rack up high scores!

## Tech Stack
- Pure HTML5 Canvas & JavaScript (ES6)
- Web Audio API (procedural sound effects, no external assets)
- LocalStorage for high score persistence
- TypeScript wrapper (`main.ts`) for make.fun bot packaging
